# Contributing

Open a GitHub issue for a format variant or a reproducible result. Include the public firmware source, the model family if relevant, the tool revision, and the exact command or test case. A synthetic sample or a minimal structural excerpt is enough to reproduce many parser issues.

Keep device serial numbers, MAC addresses, LAN addresses, account information, pairing tokens, key material, and firmware binaries out of issues and commits. Share a public vendor download reference and a digest when a sample needs to be identified.

For launcher findings, specify whether the test changed an Input menu entry, opened a web app, or placed a tile on SmartCast Home. Record whether the result survived app exit or reboot. Use hardware you own or have permission to test.
